# Code of Conduct

We want this project to be a respectful, harassment‑free place for everyone, regardless of language, background, experience, gender, age, disability, religion or nationality.

**Expected behaviour**

- Be kind and patient; assume good intent.
- Criticise code and ideas, not people.
- Accept feedback gracefully and give it constructively.
- Keep discussions on topic; use English or Persian.

**Unacceptable behaviour**

- Harassment, insults, personal or political attacks, discrimination.
- Publishing someone's private information.
- Spam, or anything illegal.

Maintainers may edit or remove contributions and block users who break these rules. To report a problem, contact the maintainers through a private GitHub security advisory or the contact address on the maintainer's profile.
