# Design notes

Version 2.11.10. The visual language lives in `aegis_desktop/ui/`; this page summarises the rules so that contributions stay consistent.

## Brand guide

**Idea:** Aegis is the shield, the vault is the treasure → *matte noir*: deep, cool, quiet. Brand constants are in `ui/brand.py`.

| | |
|---|---|
| Signature theme | `noir` (Aegis Noir): background `#060607`, panel `#0c0c0e`, neutral text, one accent — brushed platinum `#dfe2e8`. Brand themes: `noir`, `ivory`, `aegis-light`. Thirteen curated four‑colour palettes are generated by `themes_data._make`, which enforces contrast (tested for every theme). Themes removed in old preferences fall back to Noir. |
| Accent rule | The accent is a signature, not a surface: logo, the open page, the primary action, focus. Enforced by `tests/test_brand_kit.py::test_the_accent_is_scarce_on_every_page`. |
| Monogram | `brand.paint_mark`: gilt shield rim, obsidian field, arch‑A. Also renders `icon.png/.ico`, the splash and the installer art (`python tools/make_brand_assets.py`). |
| Type | Persian/UI: Vazirmatn. Latin UI: Inter. Display (Latin only): Cormorant Garamond (SIL OFL, `assets/fonts/`) for the wordmark, splash and hero. Weights come from `tokens.WEIGHT`. |
| Material | Film grain (~2 %), a two‑tone engraved divider (`EngraveLine`), lit top edge and floor shadow on cards (`paint_depth`). |
| Signature motion | Gilt glint (`GlintPass` / `HoverLight`): one soft diagonal band, once — card entry, primary button, opening vault. |
| Rituals | The vault opens/closes as two halves of the shield (`moments._Doors`); the day seal appears when the last task of today is done. |
| Voice | Short, calm, sure (`ui/voice.py`). |
| Motion rules | 120–320 ms, one ease family, nothing loops, motion only answers a user action, “Reduce motion” turns everything into instant changes. |

## System

- **Tokens** (`ui/tokens.py`): type scale, 4‑point spacing ladder, radii and durations. Stylesheets and pages read from here.
- **Controls** (`ui/system.py`): `ChipCombo`, `ChipToggle`, `ChoiceTabs`, `StepNav`; popovers share one glass style.
- **Full‑page editors** (`ui/page_editor.py`): tasks, goals and habits open as a page with a back bar, a centred column and a footer with Save/Cancel (`Ctrl+Enter` saves). Unsaved changes are confirmed on leave.
- **Date and time** (`ui/datepick.py`, `ui/timepick.py`): a Jalali calendar popover and an hour/minute grid.
- **Right‑to‑left:** painted text uses `theme.AL_R` / `AL_L` (absolute alignment); plain `AlignRight` is mirrored in an RTL application.
- **Accessibility:** spoken names for every button (`ui/a11y.py`), a High Contrast theme (text ≥ 7:1, borders ≥ 3:1), full keyboard operation.

## Tools

- `tools/chaos_gui.py` — randomised clicks, typing, drags, keys, theme/size changes and lock/unlock on a real window; any Qt warning or exception is reported with the latest actions. Example: `python tools/chaos_gui.py --seed 3 --steps 1500 --mode big`.
- `tools/leakcheck.py` — widget/object/RAM growth over hundreds of open/close cycles.
- `tools/bench.py` — timings up to 20,000 tasks.
- `tools/strip_comments.py` — builds a comment‑free copy and proves the syntax tree is identical.
- `tools/windows_qa.py` — renders every page at 100/125/150/200 % scaling on real Windows (`qa_windows.bat`).
