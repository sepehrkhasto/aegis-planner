# Aegis Planner

**برنامه‌ریز شخصی رمزنگاری‌شده و آفلاین برای ویندوز، فارسی (راست‌به‌چپ) با تقویم جلالی**

## چرا Aegis Planner

- **حریم خصوصی از پایه.** بدون حساب کاربری، بدون سرور، بدون آمارگیری. همه‌چیز در یک فایل رمزنگاری‌شده با AES‑256‑GCM است. بدون رمز اصلی، داده خوانا نیست، حتی برای خود برنامه.
- **ساخته‌شده برای فارسی.** راست‌به‌چپ، تقویم جلالی (هفته از شنبه)، ارقام فارسی و افزودن سریع فارسی («تسک بساز فردا ساعت ۱۰ جلسه»).
- **آرام و سریع.** شانزده تم (تیره و روشن)، کیبورد‑محور (پالت فرمان `Ctrl+K`) و روان حتی با هزاران تسک.
- **متن‌باز.** پروانهٔ GPL‑3.0‑or‑later؛ بخوان، بررسی کن، خودت بساز.

## امکانات

- **تسک‌ها** — دسته، اولویت، برچسب، زیرتسک، ساعت شروع/پایان، بازهٔ چندروزه، تکرار روزانه/هفتگی، پیوند به هدف، واگرد (`Ctrl+Z`)، سطل زباله با نگهداری ۳۰ روزه.
- **تقویم** — نمای ماه، هفته، روز، برنامه و سال جلالی؛ ساختن، جابه‌جایی و تغییر طول تسک با ماوس؛ مینی‌تقویم؛ چاپ (PDF).
- **کانبان**، **یادداشت‌ها** (پوشه، سنجاق، بخش‌های غنی، خروجی Markdown/PDF)، **عادت‌ها** (رگه و هیت‌مپ)، **هدف‌ها** (مرحله و پیشرفت)، **تمرکز** (پومودورو)، **گزارش‌ها** (با گزارش PDF بدون متن تسک‌ها).
- **افزودن سریع** از هر جای ویندوز (`Ctrl+Alt+Space`، اختیاری) و از پالت (`Ctrl+K`).
- **یادآور**، قفل خودکار، پشتیبان‌گیری خودکار رمزنگاری‌شده با مرور، بررسی سلامت و بازگردانی.
- **ورودی/خروجی** — ولت رمزنگاری‌شدهٔ `.aegis`، یادداشت Markdown، تقویم iCalendar (`.ics`).

## دانلود و نصب (ویندوز ۱۰ و ۱۱)

۱. صفحهٔ [**Releases**](https://github.com/sepehrkhasto/aegis-planner/releases/latest) را باز کن.
۲. فایل `AegisPlanner-Setup-<نسخه>.exe` و در صورت تمایل `SHA256SUMS.txt` را دانلود کن.
۳. صحت فایل را بررسی کن (پایین‌تر) و نصب‌کننده را اجرا کن. پوشهٔ نصب را می‌توانی انتخاب کنی. حذف برنامه هرگز داده‌ات را پاک نمی‌کند، مگر خودت بخواهی.

داده‌ها در `%APPDATA%\AegisPlanner\` ذخیره می‌شود (`vault.aegis`، `backups\`، `prefs.json`، `aegis.log`). برای محل دیگر (مثلاً فلش): `AegisPlanner.exe --data-dir "E:\AegisData"`.

### هشدار SmartScreen ویندوز («Windows protected your PC»)

نصب‌کننده **امضای دیجیتال (Code Signing) ندارد**. گواهی امضا هر سال هزینه دارد و برای همه در دسترس نیست؛ پس برای یک پروژهٔ متن‌باز رایگان، فایل اجرایی بدون امضا منتشر می‌شود. SmartScreen برای هر فایل اجرایی تازه، بدون امضا و کم‌دانلود هشدار می‌دهد. در ویندوز ۱۱، قابلیت *Smart App Control* هم ممکن است برنامه‌های بدون امضا را بدون دکمهٔ «Run anyway» ببندد؛ این قابلیت فقط روی نصب تمیز ویندوز ۱۱ روشن است و از *Windows Security ← App & browser control* خاموش می‌شود.

این هشدار یعنی «ناشر ناشناس»، **نه** اینکه فایل مخرب است. لازم نیست به هشدار یا به حرف سازنده اعتماد کنی؛ خودت می‌توانی بررسی کنی:

- **هش SHA‑256 را بسنج.** هر انتشار هش هر فایل را در `SHA256SUMS.txt` و توضیحات همان نسخه می‌گذارد. در PowerShell:

  ```powershell
  Get-FileHash .\AegisPlanner-Setup-2.11.10.exe -Algorithm SHA256
  ```

  هش چاپ‌شده باید دقیقاً با هش صفحهٔ انتشار یکی باشد. اگر فرق داشت، فایل را اجرا نکن.
- **روش ساخت را ببین.** فایل‌های انتشار با یک workflow عمومی GitHub Actions ([`.github/workflows/release.yml`](.github/workflows/release.yml)) مستقیم از کد برچسب‌خورده ساخته می‌شوند و لاگ ساخت عمومی است.
- **خودت از سورس بساز** (پایین‌تر) یا مستقیم از سورس اجرا کن.

برای ادامه: **More info ← Run anyway**.

## مدل امنیتی

| | |
|---|---|
| مشتق‌سازی کلید | PBKDF2‑HMAC‑SHA256، ۶۰۰٬۰۰۰ تکرار، نمک تصادفی ۱۶ بایتی |
| رمزنگاری | AES‑256‑GCM (با اصالت‌سنجی). یک کلید داده ۲۵۶ بیتی (DEK) ولت را رمز می‌کند و DEK با رمز اصلی wrap می‌شود |
| تغییر رمز | DEK تازه ساخته می‌شود؛ ولت و همهٔ پشتیبان‌ها دوباره رمز می‌شوند و رمز قدیمی از کار می‌افتد |
| کلید بازیابی | اختیاری، `AEGIS‑XXXXX‑…`، فقط یک‌بار نمایش داده می‌شود و مستقل از رمز، DEK را wrap می‌کند |
| ذخیره‌سازی | نوشتن اتمی (فایل موقت ← fsync ← rename) به‌اضافهٔ پشتیبان خودکار رمزنگاری‌شده |
| شبکه | به‌طور پیش‌فرض هیچ. اختیاری و پیش‌فرض خاموش: روزی یک درخواست به API عمومی GitHub برای شمارهٔ آخرین نسخه؛ هیچ اطلاعاتی از تو یا ولت فرستاده نمی‌شود |
| زیرو‑نالج | رمز اصلی و کلیدها هرگز روی دیسک نوشته نمی‌شوند. **اگر رمز را فراموش کنی و کلید بازیابی هم نداشته باشی، داده را هیچ‌کس نمی‌تواند برگرداند.** |

مدل تهدید، محدودیت‌ها و روش گزارش آسیب‌پذیری در [SECURITY.md](SECURITY.md) آمده است.

## اجرا و ساخت از سورس

به Python نسخهٔ ۳٫۱۰ یا بالاتر نیاز دارد.

```bash
git clone https://github.com/sepehrkhasto/aegis-planner.git
cd aegis-planner
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run_aegis.py
```

ساخت نصب‌کننده با `build_windows.bat` یا طبق راهنمای گام‌به‌گام [docs/BUILD.md](docs/BUILD.md) (شامل تست و امضای کد).

## تست

```bash
pip install -r requirements-dev.txt
set QT_QPA_PLATFORM=offscreen
python -m pytest tests -q
```

نزدیک به هزار تست رمزنگاری و فرمت ولت، فایل‌های خراب و خصمانه، تقویم جلالی، تکرارها، همهٔ صفحه‌ها و دیالوگ‌ها در تم‌ها و اندازه‌های مختلف و جریان‌های کیبوردی را می‌سنجند. پوشهٔ `tools/` یک تست فشار تصادفی رابط، بررسی نشت حافظه و بنچمارک هم دارد.
